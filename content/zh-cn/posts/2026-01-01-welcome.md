## 支持的语法

### 行内公式与块公式

行内公式示例：爱因斯坦场方程 $G_{\mu\nu} = 8\pi G\, T_{\mu\nu}$，或者 $\alpha + \beta = \gamma$。

块公式示例：

$$
\mathcal{L}_{\text{DNA}} = \sum_i \psi_i^\dagger \left( i\hbar \partial_t - H \right) \psi_i
$$

### 代码块

支持语法高亮：

```python
import numpy as np

def fold_energy(seq: str) -> float:
    """Naive DNA folding energy."""
    return float(np.sum([ord(c) - ord('A') for c in seq]))
```

## 如何新建一篇

```bash
hugo new posts/your-post.md     # 杂谈
hugo new publications/paper.md  # 论文
hugo new literature/review.md   # 文献讨论
```
